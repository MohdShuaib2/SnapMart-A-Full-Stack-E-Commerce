# 🛒 SnapMart - Full Stack E-Commerce Website

A modern Full Stack E-Commerce Website built using the MERN Stack. Users can browse products, add items to the cart, place orders, and enjoy a responsive shopping experience.

---

## 🚀 Features

- 👤 User Authentication (Login & Register)
- 🛍️ Product Listing
- 🔍 Search & Filter Products
- 🛒 Shopping Cart
- ❤️ Wishlist (if implemented)
- 📦 Order Management
- 💳 Secure Checkout (if implemented)
- 📱 Fully Responsive Design
- ⚡ Fast & User-Friendly Interface

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/SnapMart-A-Full-Stack-E-Commerce.git
```

### Go to Project Folder

```bash
cd SnapMart-A-Full-Stack-E-Commerce
```

### Install Dependencies

Frontend

```bash
cd Frontend
npm install
npm start
```

Backend

```bash
cd backend
npm install
npm run dev
```
